Featured Academic Project

Smart Village Resource Sharing Portal

A community-centered web application developed to bridge resource gaps in rural areas. The portal allows villagers to list, discover, and request agricultural machinery, equipment, tools, and shared community resources. Built with an intuitive Streamlit frontend and backed by an SQLite database for lightweight, reliable local data storage.

Key Capabilities:

  • ✦ Resource Management: Add, update, and manage equipment listings with availability status.
  • ✦ Interactive UI: Clean, responsive dashboard designed with Python and Streamlit.
  • ✦ Local Relational Database: SQLite integration for storing member profiles and booking requests.
  • ✦ Social Impact: Encourages collaborative resource sharing to lower farming costs.
